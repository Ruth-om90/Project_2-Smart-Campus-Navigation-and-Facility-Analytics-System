Ruth Omoyi - Facility records and ID hash table

Facilities are stored in input-file order in FacilityHashTable. Each record's
ID is trimmed and converted to uppercase before validation, hashing, storage,
or comparison. A valid ID is F followed by exactly three digits.

The table uses separate chaining. Its initial capacity is 101 buckets, and
chains can grow as needed, so the table does not impose a fixed maximum number
of facilities. The custom polynomial hash starts at zero and, for each
normalized ID character, updates the value to (value * 31 + character) modulo
the bucket count. It does not use a library hash function.

For the loading diagnostic, a collision is counted once when an accepted,
non-duplicate facility is inserted into a bucket that already contains at
least one facility. A duplicate or invalid record does not increment the
collision count. Facilities are also retained in insertion order for display.

Janiya Maduagwu - Campus graph and navigation

CampusGraph is an undirected adjacency list that stores the buildings on
the campus as well as their connections. Buildings are represented by 
their names, while the neighboring buildings are represented as a list 
of connected building indices. The building names are checked to prevent 
duplicate entries and to allow searches regardless of capitalization and
surrounding spaces.

CampusGraph uses Breadth-First Search (BFS) and Depth-First Search (DFS) 
to explore campus connections. BFS is also used to find the shortest path 
between two buildings by keeping track of the previous building in the 
search. Since the graph is unweighted, the shortest path is defined by the
fewest number of connections.

Campus connections are loaded from text files with information on the
buildings and their connections. The graph also calculates the total
number of buildings and connections in the graph, the degree of each 
building and the number of connected components. A connectivity report 
lists the buildings with the highest degree and the isolated buildings
(i.e. buildings with no connections).
